# SOPTEK — Página web

Página web de **SOPTEK (Soporte y Mantenimiento de Tecnología)**, preparada para publicarse con GitHub Pages.

## Archivos

- `index.html` — página principal.
- `soptek-logo.png` — logotipo utilizado en la página.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html` y `soptek-logo.png` al repositorio.
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios y espera a que GitHub Pages publique el sitio.

La página está diseñada para funcionar sin frameworks ni dependencias externas.
